# 城市地下综合管廊运行维护管理平台

面向管廊主体台账、入廊管线登记、廊内环境监测、通风排水消防、结构沉降与渗漏处置、巡检检修与隐患整改、入廊作业审批和运维值班的一体化城市地下综合管廊运行维护管理工作台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

### 入廊费与服务费结算专项

通用台账之外的三个专项入口（数据独立持久化在 `urban-utility-tunnel:fee-ledger`）：

| 入口 | 路由 | 责任班组（可写） | 业务对象 |
| --- | --- | --- | --- |
| 入廊费与服务费结算 | `/fee` | 收费结算班组 | 入廊服务合同、结算单、对账批次 |
| 欠费管线复核清单 | `/review` | 管线巡查班 | 欠费牵动的入廊管线复核项 |
| 保养台账对齐 | `/careledger` | 机电维修班 | 入廊设施保养台账 |

页头可切换班组身份；不是本责任班组的写操作在服务层按归属驳回（页面同步只读）。

业务口径（页面打包出的 `批次说明与裁决口径.txt` 里随附同样文字）：

- **整批出账**：按入廊服务合同和计费周期（`YYYY-Q1…Q4`）出账，首费周期含一次性入廊费，其后只收服务费；存量合同按签订日期回填。
- **重复出账**：同一合同同一周期只认最后生成的一版，旧版自动标「已作废（被新版替代）」并记录替代单号，金额不叠加。
- **对账导入**：回传 CSV 按「合同编号+计费周期」匹配有效版逐行核对；匹配上的照常入账，匹配不上的行单独列出并写明原因（合同不存在、该周期无有效结算单等），不影响其他行。
- **欠费联动**：回函已缴不足额的结算单挂欠费，并按该合同在廊管线逐条挂入复核清单；补缴结清后未处理复核项自动解除，已复核的留痕。
- **早年口头入廊补录裁决**：无书面合同的单位补录为「事实合同」（编号 `HT-BL-`），按双方确认的实际占用日回填、标「待补签」，补签前正常出账、欠费照挂，补签后多退少补。
- **复核落台账**：管线责任人提交复核即登记保养台账；既有台账照原编号（`DEVI-…`）更新，早年没登记的一律另起新行（`BY-NEW-…`）并注明原因。
- **两版取值裁决**：现场实测与台账/申报不一致时保留现场实测版，下次保养日按「本次保养日期+保养周期」回算，旧版进版本留痕。
- **整批另存**：外部文件先导进来处理，再把结算明细、逐行核对结果、欠费复核清单、保养台账和裁决说明打包成一个 ZIP 下载。

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `urban-utility-tunnel:entries` 这一项，或调用 `resetModule(模块)`。
